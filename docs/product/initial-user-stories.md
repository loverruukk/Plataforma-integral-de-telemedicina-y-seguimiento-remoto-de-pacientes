# Historias de usuario iniciales

## Gestión de identidades y roles
- Como **administrador de tenant**, quiero invitar a profesionales sanitarios para que puedan configurar sus agendas.
- Como **paciente**, quiero aceptar términos y consentimientos para acceder a mis datos clínicos.
- Como **profesional sanitario**, quiero autenticación MFA para asegurar el acceso a información sensible.

## Agenda y videoconsulta
- Como **profesional sanitario**, quiero gestionar mis huecos de agenda para ofrecer videoconsultas y visitas presenciales.
- Como **paciente**, quiero unirme a una sala de espera virtual y saber cuánto falta para ser atendido.
- Como **profesional sanitario**, quiero acceder a la historia clínica del paciente durante la videoconsulta.

## Telemonitorización de crónicos
- Como **paciente crónico**, quiero registrar mis constantes vitales desde la app para que mi equipo médico las revise.
- Como **profesional sanitario**, quiero recibir alertas cuando un paciente supere un umbral configurado.
- Como **coordinador clínico**, quiero visualizar un panel priorizado por riesgo para coordinar intervenciones.

## Integración con historiales clínicos
- Como **profesional sanitario**, quiero importar la medicación activa del HCDSNS para evitar errores de prescripción.
- Como **paciente**, quiero dar o revocar mi consentimiento para compartir datos con terceros.

## Seguridad, RGPD y auditoría
- Como **DPO**, quiero acceder a informes de auditoría sobre accesos a datos de salud.
- Como **paciente**, quiero solicitar la rectificación de mis datos y recibir confirmación de la acción.
