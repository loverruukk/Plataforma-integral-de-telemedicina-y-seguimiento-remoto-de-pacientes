# Web App

Aplicación Next.js orientada a multi-tenant para los distintos perfiles de la plataforma.

## Requisitos previos

- Node.js >= 18
- npm >= 9 (o pnpm/yarn)

## Instalación

```bash
cd packages/frontend/web
npm install
```

## Scripts disponibles

- `npm run dev`: arranca el servidor de desarrollo con hot reload.
- `npm run build`: genera el build de producción.
- `npm run start`: ejecuta el build optimizado.
- `npm run lint`: ejecuta ESLint con la configuración del proyecto.

## Primer arranque

```bash
npm run dev
```

La aplicación se sirve por defecto en `http://localhost:3000`.
